# Project and public-repository provenance

This repository is a public, fresh-history snapshot of the ChengLan music platform. It contains the application source, shared contracts, tests, a focused offline evaluation, three interface screenshots and the two tracks already presented in the public demo. The audio files are examples created through Mureka, with their prompts and settings shown in the application.

The original working project and its server release history remain separate. This snapshot excludes runtime databases, user uploads, API keys, local administrator credentials, server-specific deployment scripts and operational records. Tests use generated or fictional inputs. The screenshots show an empty or test workspace rather than private accounts.

The product concept, architecture, workflow and acceptance criteria were designed by the project owner. Development followed written specifications and used AI-assisted coding, including a spec-driven vibe-coding workflow, for implementation and iteration. The code and claims in this public edition were checked against the runnable tests and local evaluation before publication.

Mureka provides the generation API; this repository implements the surrounding product and workflow. FFmpeg handles local audio processing. Third-party UI and server libraries retain their own licenses; publishing this repository does not change their attribution.
